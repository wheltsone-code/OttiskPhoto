# Фирменный знак приложения

Единственный источник геометрии — [assets/logo.svg](./assets/logo.svg). Это оригинальный SVG сайта «Оттиск Фото», без изменений контуров; заливка #FD3977. Прежний исходник двух кругов удалён.

Для регенерации установите зависимости разработки и выполните `python tools/build_icon.py` выбранным интерпретатором проекта. [Инструмент](./tools/build_icon.py) создаёт прозрачный PNG 512 × 512 и ICO с размерами 16, 20, 24, 32, 40, 48, 64, 128 и 256. CSS-заливка исходника переводится в атрибут только в памяти рендерера MuPDF, который не поддерживает этот CSS-класс. Сам SVG не переписывается.

## Где применяется

| Место | Источник |
| --- | --- |
| EXE, значок файла, новые ярлыки | `assets/logo.ico`, обе спецификации PyInstaller |
| Главное и вспомогательные окна, заголовок, панель задач | `set_icon()` в [metadata.py](./illusive_print/metadata.py), тот же ICO |
| MSIX, меню «Пуск», изображения пакета | `assets/logo.png` через [prepare_msix.py](./tools/prepare_msix.py) |

Отдельные экраны загрузки и «О программе», содержащие прежний знак, в исходниках не обнаружены. Рабочие алгоритмы, раскладка, печать и цветокоррекция не менялись.
