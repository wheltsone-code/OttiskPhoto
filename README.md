# Оттиск Фото

**1.1.10 · Windows x64 · Python 3.13 · Store MSIX 1.1.10.0**

Фотопечать: JPG/JPEG/PNG, HEIC/HEIF, WebP, страницы PDF и совмещённые PSD,
EXIF, копии, кадрирование, RGB-кривые, PDF и прямая
печать через очередь Windows. Исходные фотографии не изменяются.

В режимах «Задать размер фото» и «Фото с рамкой» блоки «Цвет» и «Метки реза»
поначалу свёрнуты: нажмите весь заголовок или используйте Tab и Enter.
Сворачивание не отключает обработку. Размещение «Авто / Рядом / Стопкой»
независимо от выравнивания; одинаковые варианты заменяются подписью сетки.
«↺ Сбросить настройки…» требует подтверждения, сохраняет фото, копии, язык
и единицы, возвращает раскладку к одному фото на листе и сбрасывает коррекции.

## Готовый EXE

Скачайте `OttiskPhoto.exe` из раздела **Releases** этого репозитория и запустите его.
Один файл, без установщика. Каталог `dist/` содержит локальные результаты сборки
и исключён из исходников; готовый EXE распространяется вложением к релизу.
Python, Tk, Pillow/LittleCMS, ReportLab и ресурсы включены внутрь. Для прямой
печати нужен установленный Windows-драйвер принтера; PDF-просмотрщик не используется.

## Запуск из исходников

```powershell
Set-Location 'C:\Users\acer\Documents\Full'
py -3.13 -m venv .venv313
.\.venv313\Scripts\python.exe -m pip install -r requirements.txt
.\.venv313\Scripts\python.exe .\main.py
```

В существующем окружении достаточно последней команды. Активация не требуется.

Название, иконка и строка версии 1.1.10 включены в Windows Version Resource.

## Фото, копии и кадрирование

- Импорт файлов или папки без подпапок. Одинаковый путь повторно не добавляется.
  Файлы и папки можно перетащить из Проводника на главное окно, включая список
  и предпросмотр. Снимки добавляются к текущему заказу; статус показывает
  количество добавленных и пропущенных файлов. Пробелы и кириллица поддерживаются.
  Используется TkDnD (tkinterdnd2): Tcl `splitlist` сохраняет пробелы, кириллицу
  и фигурные скобки в именах. Собственный перехват WNDPROC/WM_DROPFILES удалён.
  Предпросмотр и список подсвечиваются при внешнем наведении. Кадрирование ЛКМ
  использует прежние обработчики и не становится внешним перетаскиванием.
  В строке фото есть «Копий», ввод с клавиатуры, − и +; минимум 1. «Удалить»
  исключает снимок. Копии размещаются подряд в порядке списка.
- Выбор миниатюрой или ячейкой. ЛКМ перетаскивает фото внутри неподвижной
  рамки; «Обрезать до краёв» не допускает белых полос, «Фото целиком» сохраняет весь кадр.
  Параметры принадлежат фото и применяются ко всем его копиям.
- В списке Ctrl+щелчок добавляет/снимает выделение, Shift+щелчок выбирает диапазон.
  «Удалить» и Delete при фокусе в списке убирают все выделенные строки, сохраняя
  исходники. В поле копий Delete редактирует число. Выделение сохраняется при
  перелистывании; предпросмотр обводит все копии выбранных снимков, а заголовок
  показывает «Выбрано: N фото». Кадрирование, поворот, масштаб и сброс кадра
  применяются ко всему выделению. Поворот/масштаб меняют каждое текущее значение
  на один шаг, сохраняя различия. Перетаскивание сдвигает только захваченный снимок.
  При индивидуальном цвете изменяется только затронутый параметр выбранных фото;
  их остальные параметры и коррекция остальных снимков сохраняются.
  Для неодинаковых параметров показана подсказка «Разные значения».
- Колесо над предпросмотром масштабирует лист относительно курсора, средняя
  кнопка перемещает вид, «Вписать лист» возвращает его целиком. Этот масштаб
  не меняет печатную геометрию; ЛКМ продолжает кадрировать фото.
- EXIF учитывается первым, затем длинные стороны фото и области печати
  совмещаются автоматически. «↻ 90°» добавляет ручной поворот. «Сбросить кадр»
  центрирует фото и убирает ручной поворот, сохраняя режим кадрирования.
- «− 100% +» меняет индивидуальный масштаб с шагом 10 процентных пунктов,
  минимум 100%. Размер отпечатка и раскладка сохраняются. Сброс кадра возвращает
  100%; общая команда кадрирования не переносит масштаб.
- «Применить кадрирование ко всем» переносит только «Обрезать до краёв» / «Фото целиком»,
  сохраняя индивидуальные сдвиги и повороты. Ctrl+Z отменяет жест целиком за
  один шаг, общую команду, сброс кадра и поворот. Esc отменяет текущий жест.
- Длинные имена сокращаются; полное имя показывается при наведении.
  Капсулы и выпадающие поля поддерживают Tab, Space/Enter, видимый фокус.

## Бумага и размер фото

PDF читает pypdfium2: одна страница добавляется сразу, для многостраничного
документа доступны все страницы или диапазон (например `1–3, 7`). Для папки
один раз выбирается «Все страницы / Только первые страницы / Пропустить PDF».
Каждая страница — отдельное фото со своими копиями, кадром и цветом;
дубликаты определяются парой «путь + номер страницы». Импортируются миниатюры,
а вывод заново растеризует оригинальную страницу под разрешение и кадрирование.
Вектор исходного PDF в экспорт не переносится. «Взять размер страницы из PDF»
берёт физический CropBox (или MediaBox) с поворотом, задаёт размер фото и
сохраняет бумагу. Защищённые/повреждённые PDF пропускаются с причиной.

PSD читает psd-tools только из сохранённого совмещённого изображения,
без пересборки слоёв/эффектов. ICC преобразуется один раз в существующем
пути sRGB; прозрачность заполняется белым. Для PSD без совместимого превью
предлагается сохранить с максимальной совместимостью или экспортировать PNG/TIFF.
Проблемный файл не прерывает остальные элементы партии.

- «Русский / English» и единицы («мм / дюймы», в English — «mm / in») независимы. Выбор сохраняется
  в `%LOCALAPPDATA%/OttiskPhoto/preferences.json`. Язык меняется без сброса заказа
  и открытого листа; родное окно драйвера использует системный язык.
  Геометрия хранится в мм, поля ввода и подписи преобразуются через 1 in = 25,4 мм.
  Переключение единиц не записывает округлённое отображение обратно в размеры.
- В выпадающих списках показаны обе системы. 4×6″ (101,6×152,4 мм),
  5×7″ (127×177,8 мм) и 8×10″ (203,2×254 мм) — отдельные пресеты фото,
  US Letter (215,9×279,4 мм) — отдельный формат бумаги. Бумага 13×18 см
  (130×180 мм) и 5×7″ (127×177,8 мм) также представлены отдельно.

- «Бумага» задаёт весь лист: 10×15, 13×18, 15×21 см, A4, A3 или свой формат.
  Ориентация доступна в обоих режимах. Размеры — от 1 до 2000 мм.
- «Разделить лист»: 1/2/4/6/9 вручную; по умолчанию 1. Выбор количества
  сохраняется между запусками в `preferences.json` (поле `photos_per_sheet`),
  переключение языка/единиц его не удаляет. Для двух фото книжный лист делится на
  верх/низ, альбомный — на левую/правую половины. Неполный лист сохраняет сетку.
  Свободные места показаны пунктиром, под листом — число занятых мест.
  Выбранная копия выделена яркой обводкой, остальные копии того же фото — тонкой.
  Эти обозначения не выводятся в PDF и печать.
- «Задать размер фото»: «Размер фото» — 100×150, 130×180, 150×210 мм, A4 или свой.
  Вместимость вычисляется сравнением прямоугольных сеток с поворотом всех
  областей на 90°. Размер фото не меняется ради вместимости. Например,
  90×120 мм может разместиться как 120×90 мм. Остальные копии переходят
  на следующие листы. При нулевой вместимости вывод блокируется с причиной.
- В «Задать размер фото» автовыбор сначала сравнивает вместимость, затем высоту
  полной сетки. Если подходят обе ориентации отпечатков, доступны «Авто / Рядом /
  Стопкой». Шесть кнопок независимо выравнивают группу по горизонтали и вертикали
  внутри полей; по умолчанию обе оси центрированы. На неполном листе выравнивается
  занятый блок. «Сохранять позиции на всех листах» использует полную сетку,
  сохраняя координаты для резки стопкой. Один расчёт служит предпросмотру, PDF и печати.
- Поля и зазор доступны в обоих режимах. Стрелки имеют шаг 1 мм, ручной ввод
  принимает дробные значения с точкой или запятой. Минимум — 0 мм, значение по
  умолчанию для заданного размера фото — 3 мм. Непечатаемые поля драйвера не меняют раскладку.
- Переключение режимов восстанавливает их отдельные настройки в текущем сеансе.
- Новый запуск всегда открывает «Разделить лист» с одним фото на листе.
  Начальный вариант заданного размера — «Свой размер»; выборы сохраняются при
  переключении режимов в текущем сеансе. Общий сброс возвращает эти значения.
- «Исходный размер» вычисляет миллиметры из пикселей после EXIF-поворота по
  текущим 300/600 ppi проекта: `мм = px × 25,4 / ppi`. DPI файла игнорируется.
  Поля показывают две цифры после запятой; замок связывает стороны с пропорциями фото.
  Смена ppi сохраняет заданные миллиметры; кнопка пересчитывает размер при нажатии.
  PDF сохраняет собственный физический размер страницы.
  Размер фото общий для заказа; обычный выбор другой миниатюры его не меняет.

## Фото с рамкой и метки реза

- Третий режим использует ту же сетку точных размеров, копии и выравнивание.
  Пресеты: Polaroid 600 / SX-70 / i-Type, Instax Mini, Square и Wide.
  Размеры карточки и окна хранятся отдельно от отступов шаблона; показаны в панели.
  «Свой шаблон» задаёт карточку, окно и отступы сверху/слева в мм.
  Выход окна за карточку блокирует вывод с объяснением.
- Вместимость считается по карточке. Поворот сетки поворачивает всю карточку,
  включая окно и снимок. Кадрирование, масштаб и сдвиги меняют только снимок;
  цветокоррекция оставляет белую рамку белой. Экранная граница не выводится.
- «Метки реза» / Cut marks: «Нет / Линии / Метки», с отдельным выбором для каждого режима.
  Для «Фото с рамкой» по умолчанию выбраны «Линии»; они работают и при свёрнутом блоке.
  Отступ внутрь не меняет раскладку и масштаб: 140×140 мм при 2 мм дают 136×136 мм.
  Неположительный итог блокирует вывод. «Нет» игнорирует отступ.
- Линии толщиной 0,1 мм объединяются по общим участкам. Метки удлинены:
  2,8 мм наружу и 1 мм внутрь от границы реза. Короткий заход может остаться
  видимым после резки; итоговый размер и положение реза сохраняются.
  При нехватке места приложение предлагает увеличить поля или зазор и блокирует
  вывод. Пунктир контура в режиме меток служит только экранной подсказкой.
  PDF содержит векторные линии/метки; предпросмотр и печать используют те же координаты.
- «Лист по размеру карточки» задаёт точный пользовательский размер бумаги по
  шаблону, ориентацию, нулевые поля и зазор. Каждая карточка/копия занимает свою
  страницу. Для карточки во весь лист метки обрезаются по странице, без изменения
  её размера или сдвига карточки. Обычный экспорт PDF сохраняет текущую раскладку;
  для нескольких карточек на листе выберите A4 или другой формат бумаги.

## Коррекция и ICC

- Рабочее пространство — sRGB. Пригодный встроенный ICC преобразуется через
  LittleCMS; RGB без ICC считается sRGB. Нечитаемый или несовместимый встроенный
  ICC явно сообщается, такой файл не импортируется. Исходник сохраняется.
- Единый порядок: **входной ICC → sRGB → температура/оттенок → сочность → Gamma → RGB-кривая**.
  Температура и оттенок: −100…+100, точный ввод с точкой/запятой, шаг 0,5.
  Поканальный подъём в линейном sRGB: теплее R+G, холоднее B, пурпурнее R+B,
  зеленее G. У пар каналов разные коэффициенты. Кривая монотонна, закрепляет
  чёрный и белый и плавно ограничивает подъём в светах. Компенсации яркости нет:
  светло-серый реагирует, чистый белый сохраняется. При 0/0 коррекция пропускается.
  Двойной щелчок сбрасывает только соответствующий ползунок.
  Сочность −100…+100, шаг 1; приглушённые цвета усиливаются сильнее насыщенных,
  серые сохраняются, телесные оттенки мягко защищены. Двойной щелчок — 0.
- Gamma в дополнительных настройках: 0,50–2,00, шаг 0,01; двойной щелчок — 1,00.
  Активная Gamma показана в редакторе кривых. «Сбросить цвет» сбрасывает
  температуру, оттенок, сочность и Gamma только в активном наборе, сохраняя кривую.
- Кривые немодальны. ЛКМ добавляет/двигает точки, ПКМ или Delete удаляет
  промежуточную точку; стрелки двигают выбранную. Плавная PCHIP-интерполяция
  без выбросов; одна LUT256 для каждого из R/G/B. Диагональ нейтральна.
- Галочка ✓ «Индивидуально для выбранного фото» находится в блоке «Цвет»
  и управляет всеми пятью параметрами, включая кривую. При включении копируются
  текущие общие значения; прежняя индивидуальная кривая сохраняется. Дальнейшие
  изменения действуют только на фото и его копии. Без галочки используются
  актуальные общие настройки. Заголовок показывает активную область; при выборе
  другого фото обновляются значения и галочка. В редакторе кривых второй галочки нет.
- «Сбросить кривую» действует только в активной области и сохраняет
  индивидуальную галочку. «Готово» закрывает редактор. «До / После» меняет
  только предпросмотр, все выводы используют выбранную коррекцию.

## Разрешение и PDF

Общая настройка «Разрешение вывода» — 300 или 600 ppi для PDF и печати.
Размеры бумаги, фото, полей и зазоров хранятся в мм. Финальные изображения
заново получаются из исходных пикселей с одним Lanczos-пересчётом, включая
обрезку. Миниатюры и ранее масштабированные результаты для вывода не используются.
При недостатке пикселей под листом показан эффективный PPI выбранного фото
после кадрирования; увеличение растра до 600 ppi не добавляет деталей.

PDF создаётся ReportLab, изображения помечены ICCBased sRGB, добавлен sRGB
OutputIntent. Размеры в PDF заданы в физических единицах; меток реза нет.
Экспорт атомарный: при ошибке прежний PDF не заменяется незавершённым файлом.

## Прямая печать

«Печать…» фиксирует текущий макет, фото, копии, коррекцию и открытый лист.
Диалог предлагает принтер, 300/600 ppi, «Все листы» (по умолчанию) или
«Текущий лист», управление цветом и сводку с фактическим числом отпечатков.
Текущий лист берётся из зафиксированной страницы, новая раскладка не строится.

«Свойства принтера…» открывает родное окно драйвера для текущего задания.
При выборе принтера приложение читает форматы его драйвера и предлагает
точное совпадение физических размеров, затем ближайшее допустимое с учётом
ориентации. Названия при подборе не используются. Если подходящего формата
нет, сохраняются текущие параметры драйвера и доступны его свойства.
Возвращённый DEVMODE с закрытой частью драйвера
сохраняется для задания. Принятые физические размеры проверяются через
новый контекст из полного DEVMODE текущего задания, а не системных настроек.
Отмена свойств сохраняет предыдущие параметры задания. Физический размер
бумаги проверяется отдельно от печатной области. Близкий формат отличается
по каждой стороне не более чем на 3,2 мм **и** 3% стороны макета одновременно.
При точном или близком формате доступна обычная кнопка «Печатать».
Сводка показывает название/размер бумаги драйвера и размер макета; для меньшей
бумаги появляется предупреждение об обрезке краёв. Этот допуск не масштабирует
фото: PDF сохраняет размер макета, печать выполняется в масштабе 100%.
Ручной выбор в свойствах не заменяется повторным автоподбором.
При большой разнице или
неизвестном формате показаны результат проверки и две команды: вернуться
в свойства либо «Печатать с настройками драйвера» с отдельным подтверждением.
Во втором случае макет передаётся в масштабе 100%, без подгонки, с предупреждением
о возможной обрезке. Копий драйвера — 1: экземпляры уже размещены приложением.
Открытие принтера, создание контекста и создание задания имеют разные ошибки.

Параметры свойств, размер свежего контекста и сводка записываются в
`%LOCALAPPDATA%/OttiskPhoto/diagnostics.jsonl`. Закрытые данные драйвера
фиксируются размером и контрольной суммой, без записи их содержимого.

PDF записывается через временный файл и атомарную замену. Если существующий
файл занят или папка недоступна, доступны «Повторить», «Сохранить под другим
именем» и «Отмена». Повтор использует уже подготовленный PDF; исходный файл
остаётся целым, временные файлы удаляются после завершения или отмены.
MediaBox и CropBox задаются напрямую из миллиметров независимо от ppi растра.

Для точного размера отключите «Без полей», подгонку и увеличение в драйвере.
Непечатаемые края могут обрезать содержимое; увеличьте поля листа вручную.
Состояние «Без полей», внутреннее увеличение и закрытые настройки
цветокоррекции драйвера автоматически не проверяются.

- **Цветом управляет принтер** (по умолчанию): передаются sRGB-пиксели,
  преобразование выполняется драйвером/устройством. Приложение не применяет
  выходной ICC, системное повторное преобразование GDI отключено.
- **Цветом управляет Оттиск Фото**: выберите установленный или внешний
  `.icc`/`.icm`. Поддерживаются обычные RGB-профили вывода; CMYK, Lab
  и DeviceLink для RGB-транспорта GDI отклоняются до отправки.
  Применяется одно преобразование sRGB → выходной ICC; WCS и старое
  согласование полутонов отключаются через ICM_DONE_OUTSIDEDC.
  Вручную отключите цветокоррекцию в свойствах принтера: приложение
  не утверждает, что закрытая настройка драйвера отключена.
- Профиль запоминается для принтера, бумаги, раскладки и публичных настроек
  носителя/качества/цвета драйвера. Файл настроек — `%LOCALAPPDATA%/OttiskPhoto/profiles.json`.
  Недоступный профиль требует повторного выбора и блокирует отправку.

После подтверждения кнопка блокируется, повторный Enter игнорируется.
Показывается «Подготовка листа X из Y». До StartDoc можно отменить подготовку:
задание Windows тогда не создаётся. После передачи показывается
«Отправлено в очередь печати». Ошибка явная, кнопка восстанавливается;
автоматического повтора и перенаправления в просмотрщик нет.

### Быстрый предпросмотр

Для окна используются экранные копии исходников и кэш готовых ячеек.
Коррекция цвета выполняется после уменьшения до нужного экранного размера.
Выделение меняет только обводки; сдвиг или индивидуальная коррекция обновляют
только затронутые отпечатки. Копии одного фото используют общий кэш ячейки.
PDF и прямая печать по-прежнему обрабатывают оригиналы с выбранными 300/600 ppi.

Кэш экранных изображений ограничен 192 МиБ, полноразмерных — 128 МиБ.
Это лимиты сохранённых растров, а не всей памяти процесса: рабочие буферы,
текущий лист и изображения Tk учитываются дополнительно. Крупное изображение,
превышающее бюджет, обрабатывается без сохранения в кэше.

Воспроизводимый замер (создаёт девять тестовых JPEG 4000×3000, A3):

```powershell
.\.venv313\Scripts\python.exe .\tools\benchmark_preview.py --ui
```

выбор фото — 32,89 мс, сдвиг одного фото — 4,87 мс,
изменение общей температуры — 108,86 мс. Импорт и первый показ — 2,36 с.
Это локальный синтетический замер; результаты зависят от файлов и ПК.
Отчёт: `tmp/preview-benchmark/ui-after.json`.
